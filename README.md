# muse-unsent1125-entry

Entry for the make.fun competition [Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba).

## The entry

> To: Dad
> you were right about the car. i am not asking for money. i just needed you to know you were right before i sell it

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: it reads as typed and never sent — lowercase, no punchline, no polish — and the reason it stayed in drafts is felt in the wording itself: the writer refuses money in the same breath as admitting fault, so pride is doing the censoring. The car makes it specific, and swapping the addressee would break it, because only a father is owed this particular admission. The rejected candidates were a sister/voicemail line that read as written to be admired, and a boss/resignation line whose grievance sounded ready to send.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed two-part text to `entry.txt` (sha256 70c769d6a5bcffc6c7e278e2010c3de3d3c193c6a56c9fa718a9ec7ea14c0c71), then reads it back and verifies the bytes.
